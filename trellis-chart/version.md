# Trellis Chart 版本紀錄

Tableau viz extension，把一個度量依維度成員拆成多張小圖（small multiples）。

## 版序規則

- 每次發行都另存一份 manifest，檔名帶版序：`trellis-chart-vXX.XX.trex`，舊檔保留不刪。
- 三個地方的版號一致：檔名（`v00.05`）、manifest 內的 `extension-version`（`0.5.0`）、設定對話框標題旁的版號（`v0.5`）。
- 本檔每一節對應一份 `.trex`；標題即檔名。
- 「需重新加入」：manifest 有變更，Tableau 要先移除 extension 再加入新的 `.trex`。「Reload 即可」：只改了 HTML / JS / CSS。
- `index.html`、`extension.js`、`style.css`、`config.html` 只保留最新版；同一個網址底下的 `.trex` 載入的都會是最新程式，只有 tile 定義（名稱、提示、可放幾個欄位）是舊的。v00.08 起網址改為 GitHub Pages，v00.07 以前指的是 `localhost:8765`，兩者不通用。

## v00.06 — 2026-09-20 — `trellis-chart-v00.06.trex`

Reload 即可（manifest 與 v00.05 相比只改了 `extension-version`；已載入 v00.05 的不必重新加入）。

**新增：副軸「0 基準線對齊」**
- 「與主軸的關係」多一個選項：不共軸，但 0 基準線對齊。主副軸各用自己的刻度，但 0 落在同一個高度，副軸的負值會畫在長條站立的基準線下方。
- 適用情境：副軸是利潤率這類可能為負的度量，要一眼看出哪些分格落在負值區。
- 基準線的高度由主軸優先決定；主軸沒有負值時，副軸的負值區最多佔圖高的 40%。直軸範圍選「各分格獨立」時逐格計算，只有出現負值的分格會抬高基準線。
- 0 不在分格底部時，畫一條細的基準線；主軸本身有負值時也適用。
- 圖例在副軸名稱後標示「副軸，0 對齊」。
- 此模式下「副軸起點」設定不起作用（副軸一定包含 0）。

**其他**
- 瀏覽器 demo 新增 `?demo=margin` 範例資料（副軸為有正有負的利潤率），用來驗證此功能。

## v00.05 — 2026-09-20 — `trellis-chart-v00.05.trex`

需重新加入。

**新增：雙軸**
- C 數值可放 2 個度量：第一個是主軸（C1），第二個是副軸（C2）。
- C1、C2 各自選圖形：長條、折線、面積、甘特。甘特為每期一條短橫線，適合目標值、去年同期。
- 繪製順序固定為面積、長條、甘特、折線，折線不會被蓋住。主副軸都選長條時，副軸畫成主長條內的細長條。
- 「與主軸的關係」：不共軸（副軸用自己的刻度，預設）或共軸（同一個刻度）。
- 「副軸起點」：自動範圍（預設）或從 0 開始；只影響不共軸的折線與甘特，長條與面積一律從 0 開始。
- C1、C2 各有數字格式與小數位。數字格式新增兩種百分比：數值 × 100（0.85 → 85%）、只加 % 符號（85 → 85%）。
- 副軸顏色可自訂；「主副軸對調」開關，供膠囊順序與預期不符時使用。
- 圖例左側列出兩個度量與各自的圖形符號，並標示共軸或副軸；工具提示同時顯示兩個值。
- D 放維度（堆疊分色）時，副軸只支援折線與甘特，每個成員各畫一條；選長條或面積時不畫，並在圖例說明。

**調整**
- 設定對話框重新分區：版面、C1 主軸、C2 副軸、D 顏色、標示、樣式。
- 年份標記會同時避開主副軸的圖形。
- 設定變更後一律重新讀取資料（對調主副軸需要）。
- C tile 的提示文字改為說明可放 2 個度量。

**manifest 變更**：C 的 `fields max-count` 由 1 改為 2；C 的 tooltip 文字。
