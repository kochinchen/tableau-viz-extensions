版面

填 0 為自動；直向列數 = 分格總數 ÷ 橫向格數（無條件進位） 填 0 為全部縮放塞進窗格、不出現捲軸；分格很多時可填 80–120，超出就改為上下捲動

C1 主軸（C 的第一個度量）

副軸也跟著這個設定：各分格獨立，或所有分格共用

C2 副軸（C 的第二個度量，選填）

主副軸都選長條時，副軸畫成主長條內的細長條 只在「不共軸」且圖形為折線或甘特時有差別；長條與面積一律從 0 開始。選「0 基準線對齊」或「共軸」時，副軸一定包含 0

D 顏色

D 放度量（如年增率）時生效；放維度則改為堆疊分色

樣式

這裡不是圖表標題。填入分格（A 的成員）名稱的一部分，該分格的標題會改用強調色，方便在一堆小圖裡找到它；多個以逗號分隔
用在：被強調的分格標題、D 放度量時的衰退色與其年份標記。取消「依主題」自選顏色時，沒有依度量上色的長條也會改用這個顏色
