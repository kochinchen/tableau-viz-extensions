Trellis Chart Settings v0.9

Layout

0 = automatic. Rows = number of panels ÷ columns, rounded up 0 = shrink everything to fit the pane, never scroll. With many panels, try 80–120: the pane scrolls vertically once rows would get shorter than this

C1 · Primary axis (first measure on C)

The secondary axis follows the same choice: independent per panel, or shared across panels

C2 · Secondary axis (second measure on C, optional)

When both axes use bars, the secondary bar is drawn as a thin bar inside the primary one Only matters for "Separate" with a line or gantt; bars and areas always start at 0. With "zero baselines aligned" or "Shared", the secondary axis always includes 0

D · Colour

Applies when D holds a measure (e.g. YoY %). A dimension on D stacks the bars by member instead

Labels

Style

This is not the chart title. Type part of a panel name (a member of A) and that panel's title switches to the accent colour, so it stands out among the small charts. Separate several with commas
Used for highlighted panel titles, and for the drop colour and its year marker when D holds a measure. If you untick "From theme" and pick a colour, plain bars (not shaded by a measure) use it too
